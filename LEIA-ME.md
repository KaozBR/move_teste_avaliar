# Move — Prototipagem AS

Este pacote contém o **site funcional** (Home, Cadastro, Login, Contato, Aluno, Administradora e Saída).

**Comece pelo arquivo [`README.md`](README.md)** para executar no Visual Studio Code pelo Live Server e testar os fluxos.

- Código: `*.html`, `styles.css`, `app.css`, `script.js`, `store.js`, `app.js`.
- Dados de demonstração: `data/dados-iniciais.json`.
- Testes: `node tests/test_store.cjs`.
- Guia do GitHub: `docs/COMO-USAR-GITHUB.md`.

Os dados ficam no navegador local e **não** substituem um servidor ou banco de dados real.
