# Move — projeto integrado com Home fiel ao SVG

As telas existentes de Login, Cadastro, Contato, Aluno e Administração **não foram redesenhadas nem substituídas**. Apenas `index.html`, `styles.css` e `script.js` da Home foram atualizados para que seus botões funcionem.

Abra esta pasta no VS Code e execute `index.html` com Live Server. A Home tem Início, Contato (rolagem à localização), Fale conosco (página Contato), Entrar (página Login), Voltar ao início, mapa ampliado e menu responsivo. O formulário de contato e o login funcionam **em modo de demonstração local**, sem backend compartilhado.

As outras páginas usam as mesmas regras do projeto completo enviado anteriormente. Nunca registre dados reais de clientes neste protótipo.
